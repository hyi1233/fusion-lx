## 二、项目设计（最终架构，用户多轮纠偏后定案）

### 2.1 核心决策（必须遵守，勿再走回头路）

1. **洛雪原版 UI 一律保留，一行不改**。不自研界面、不自研取链（洛雪 musicSdk 已调教好签名/Referer/封面/榜单）。教训：曾自研网页 UI+重写取链，被用户否定"扔掉人家轮子"。
2. **唯一增量**：播放页右下角"歌词动态"悬浮按钮 → 弹窗选择器（17 种 Folia 模式 + 背景 + 混乱效果）。
3. **网页版（fusion-music 的 UI 部分）已冻结**，只作观察窗口；它的 WebView 歌词层代码（src/webview/**、src/merge/**）是活资产，产物同步进 fusion-lx 的 android assets。
4. 技术方案：RN WebView 全屏承载 Folia `VisualizerStage`（上游零改动），postMessage 桥驱动；`FoliaAssetServerModule` 进程内 127.0.0.1 静态服务器提供 assets（file:// 下 Chromium 拒载 ES module/worker）。
5. 数据流全走洛雪：`useLrcSet()/useLrcPlay()` → 桥命令 setLines/setCurrentTime；洛雪 Line.time(ms)→秒减 0.1s 对齐。

## 四、遇到的问题（已知问题清单）

### 阻塞性坑（环境，不是代码 bug）
1. **宿主 TUN 代理（Clash fake-ip 198.18.0.0/15）**：App 内所有音源请求 Network request failed。解法：`adb shell settings put global http_proxy 10.0.2.2:7890`。注意代理与 Metro 互斥 → 必须用自带 bundle 的 APK。
2. **裸 debug APK 不含 index.android.bundle** → 必红屏。重打包命令：
   ```
   cd /Users/caiqing/fusion-lx && PATH=/Users/caiqing/fusion-lx-env/node-v20.20.2-darwin-arm64/bin:$PATH \
     npx react-native bundle --platform android --dev true --entry-file index.js \
     --bundle-output android/app/src/main/assets/index.android.bundle --assets-dest android/app/src/main/res
   cd android && JAVA_HOME=/Users/caiqing/fusion-lx-env/jdk-21.0.13+9/Contents/Home ./gradlew assembleDebug
   ```

### 代码遗留问题（V2/V3 目标）
3. **App 内音频换源失败**（搜索/歌词/UI 正常，拉流不通）——V2 修。
4. **弹窗语言跟随系统而非 App 内设置**——V2 修。
5. **WebGL transparent 颜色格式不支持**（swiftshader 软渲染告警，真机待验证）——V3 兜底。
